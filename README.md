**Hive Smart Mess Management System**

A modern web-based Hostel Mess Management System that simplifies hostel dining operations for students and administrators. The application provides an easy-to-use interface for managing meal schedules, menus, student registrations, attendance, feedback, and announcements.

**Features**

- Student Login & Registration
- Secure Admin Dashboard
- Digital Meal Attendance
- Weekly & Daily Menu Display
- Student Profile Management
- Mess Announcements & Notifications
- Responsive Design for Mobile and Desktop
- Easy Navigation with Modern UI

**Technologies Used**

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Google Sheet
- Google App Script 


##  Future Enhancements

- Online Meal Booking
- QR Code Attendance
- Online Payment Integration
- Email & SMS Notifications
- Food Waste Analytics
- Firebase Database Integration
- AI-based Meal Recommendation




Hive is a web-based Hostel Mess Management System developed as a college mini project. It demonstrates a practical approach to digitizing hostel mess operations by providing a simple, organized, and user-friendly platform for students and administrators.
